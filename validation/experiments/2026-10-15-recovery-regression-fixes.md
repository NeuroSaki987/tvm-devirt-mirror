# PR #4 全量审查后的回归修复

2026-10-15。旧 PR #4 已关闭，本次不重开、不合并 master。

## 根因和处理

表达式恒等式本身正确，不保证现有 Explorer 对改写后的图仍能构造正确 SSA。SGuard 0x140057550：第一遍 17 块 clean，第二遍切参后已有 388 个 nondominating_params，phi 简化后变成 512 个。此处存在继承 scratch 值引用不支配当前块的旧参数，不能靠按寄存器名字全局改名来消除检查。

另两处闭合退步 ACE-Base64 0x18034ec50、SSC64 0x1800f64e0 经三个开关的 8 组合对照，均由高级比较配置触发；布尔认证和 join 重放不是必要触发条件。当前缺少足够的路径/内存信息去直接闭合高级表达式的前沿。

因此本次修复的是 **可选化简的提交边界和错误图输出**，没有宣称完成通用 Memory SSA 重构：

- 默认配置只在图结构无效时重试；正常 clean 的部分恢复不会平白重算。
- 开启高级比较或布尔认证时，结构无效或闭合失败可以重试一次保守表达式配置。
- 保守配置仅关闭新增的 x-(x^k) 形状改写、高级比较和布尔认证；强制位 XOR、混合位宽边界和字节提取等正确性修复仍保留。
- 只有回退结果未超时、结构有效，且能替代无效图或将原失败结果完整闭合时才采用。不会用一个新的 dirty 图替换原图，也不会用较少 unresolved 的部分图包装收益。
- 重试采用剩余 wall-clock，多个重试恢复 pass 共享截止时间；诊断时间使用累计计数与时钟快照扣除，避免切 pass 抹掉诊断时间抵扣。
- 表达式配置线程隔离，嵌套/异常退出恢复；拒绝重试时，诊断 sink 和 final pass 一并恢复，防止失败试验覆盖最终图的原因。
- `devirt` 在图不满足结构约束时返回错误，**不再生成机器码**。批量 write-devirt 原本已有此门槛。合法部分恢复仍按既有规则处理，不能计作完整恢复。
- census 外部进程保护默认改成 300 秒，留出工具原有两遍各 120 秒的空间，避免用 65 秒保护误判较慢构建。工具恢复预算没有因此调大。

## 必须纠正的成绩口径

独立审查的 4651 入口统计是 **自报完整**，不是结构有效的完整数。将其与原始结构记录联结后：

- 默认新增 2 例（0x14002bd60、0x1400526f0）均有 SSA 错误，虽然基线也 dirty，仍不能计为有效恢复。本版本将拒绝输出它们的无效图，而不是继续宣传 +2。
- 高级新增 209 例中，旧审查有 191 个 clean、16 个 dirty、2 个缺少结构报告。191 是旧提交的交叉检查结果，不是本修复的新全量成绩。
- 本次对已报告的 6 个候选独有结构退化入口、2 个真实闭合退步完成定向修复；没有把另外两个 65 秒保护造成的 core3 超时当算法退步，也没有靠追加恢复预算修复。

已知基线遗留的无效图不保证都能重算成有效图；仍无效时失败退出是预期保护，不能当作成功，也不能与旧版错误输出直接按数量比较。
